# Evidencias

Esta carpeta se llena al ejecutar `scripts/capturar-evidencias.ps1`:

- `capturas/` : una captura de pantalla por paso (PNG).
- `logs/` : salida de texto de cada paso.

Capturas manuales requeridas (no se pueden automatizar): ejecución del pipeline en GitHub Actions (verde y una ejecución fallida por quality gate), protección de rama, y dashboard de SonarCloud.
